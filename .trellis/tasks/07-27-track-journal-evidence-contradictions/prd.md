# Route journal evidence contradiction fixes

## Goal

Identify the producer of contradictory generated journal prose and route a durable fix so session records match the validation or review evidence that actually ran.

## Background

Recent downstream sessions surfaced generated journal/session prose that stated validation or review evidence was not recorded even when full checks and PR review work had run. Prior local source searches did not confirm the exact wording in Trellis core, so this task should first establish the producer and then route the fix to the owning repo.

## Requirements

- Identify the producer of the contradictory journal wording, including whether it comes from Trellis session scripts, bundled Trellis templates, or sd-ai-command-pack lifecycle tooling.
- Define the expected contract for validation/review evidence in generated session records.
- Ensure generated journal entries either reflect the checks that actually ran or omit the section when evidence is unavailable.
- Avoid ad hoc parsing of free-form prose when structured validation or review data is available.
- If implementation ownership is outside Trellis, create or link the external handoff and keep this task as the Trellis tracking record.

## Acceptance Criteria

- [ ] The owning producer for the contradictory wording is identified.
- [ ] The Trellis-owned fix or external handoff prevents generated records from saying validation was missing when evidence exists.
- [ ] A regression test or explicit external validation case covers the contradictory wording.
- [ ] Trellis session contracts remain documented if Trellis-owned behavior is involved.
- [ ] Any external issue, PR, or task needed for sd-ai-command-pack ownership is linked from this task.
